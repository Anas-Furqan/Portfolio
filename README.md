## 🎯 Two Modes

| Professional | Terminal |
|------|----------|
| Clean, polished showcase | Hacker-style terminal interface |
| Projects, skills, achievements | Command-line navigation |
| Modern UI with animations | Retro CLI experience |

---

## ✨ Features

- 🎨 **Dual Interface**: Toggle between Professional & Terminal modes
- ⚡ Smooth animations with Framer Motion
- 🌙 Premium dark UI with Tailwind CSS
- 📦 Achievement & project modal system
- 📱 Fully responsive design
- ⚙️ TypeScript for type safety

---

## 🛠 Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion
- **UI Components**: Lucide React


---

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Dev server (localhost:3000)
npm run dev

# Build for production
npm run build
```
